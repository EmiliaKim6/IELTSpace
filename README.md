# IELTSpace

一个纯本地运行的雅思阅读备考工具：题库浏览、限时练习、错题本、单词背诵（SM-2 记忆算法）、学习统计与热力图，全部数据保存在浏览器本地，无需联网、无需注册。

![Tech](https://img.shields.io/badge/stack-HTML%20%2F%20CSS%20%2F%20Vanilla%20JS-orange.svg)

---

## ✨ 功能一览

### 📊 学习总览
- 按分类展示题库卡片，快速进入各套练习

### 📚 题库浏览
- 内置 **260+ 篇雅思阅读真题**（P1 / P2 / P3 全覆盖，含 PDF 原文与 HTML 题目）
- 支持关键词搜索、题型筛选（阅读 / 听力）、频率筛选（高频 / 中频 / 低频）
- 支持按频率、难度排序，可记住列表浏览位置
- **阅读背题模式**：复用统一阅读页，直接查看答案、解析与原文定位高亮，可随时切换回测试模式

### 📝 练习记录
- 自动统计已练题数、平均正确率、学习时长、连续学习天数
- **练习趋势图**：支持最近十次 / 七天 / 一月 / 20 次多范围切换
- **练习热力图**：GitHub 风格的月度做题量热力图
- 自定义组件：中高频余量进度、阅读错题题型雷达图
- 练习历史支持筛选、批量删除、**一键导出 Markdown**

### ❌ 错题本
- 练习中答错的题目自动收录
- 掌握度机制：重练答对 2 次标记为「已掌握」
- 按 P1/P2/P3 分类、掌握状态筛选，多种排序方式
- 支持总错题分析

### 📖 单词学习
- 基于 **SM-2 间隔重复算法** 的记忆系统
- 子模块：记忆卡片、单词测试、词库管理
- 统计总词汇、已学、今日待复习、掌握率
- 支持 AI 分析（需配置 API）

### ✨ 更多工具
- **全屏时钟**：模拟指针 / 翻页 / 数字 / 低对比度四种样式，陪伴专注时刻
- **成就系统**：解锁学习徽章与荣誉
- **新手引导**：首次使用自动展示功能导览

### 🎨 主题系统
内置 5 套精美背景主题，支持动态效果：
| 主题 | 类型 |
| --- | --- |
| 晨雾群山 Misty Mountain | 动态 |
| 深海孤航 Teal Ocean | 动态 |
| 落日雾花 Floral Bloom | 静态 |

### 💾 数据管理
- 创建备份 / 备份列表 / 导出数据 / 导入数据
- 所有学习数据存储在浏览器本地（LocalStorage / IndexedDB），支持完整性检查

## 🚀 快速开始

### 方式一：直接打开（推荐）
本项目是纯静态页面，直接用浏览器打开 `index.html` 即可使用。

### 方式二：本地服务器（功能完整）
部分功能（如加载题库文件夹、AI 分析代理）需要通过本地服务器运行。

**Windows 用户**：双击 `启动服务器.bat`

**或手动启动**（需要 [Node.js](https://nodejs.org/)）：

```bash
node server.js
```

然后访问 <http://localhost:8080>

> `server.js` 是一个零依赖的 Node 静态文件服务器，同时内置了对 `token.sensenova.cn` 的 API 代理，用于 AI 分析功能。

## 📁 项目结构

```
yasi-main/
├── index.html            # 主页面（单页应用入口）
├── server.js             # 本地静态服务器 + API 代理（零依赖）
├── 启动服务器.bat         # Windows 一键启动脚本
├── css/                  # 样式文件（含 HeroUI 桥接层、引导页样式）
├── js/
│   └── bundles/          # 打包后的 JS 模块（运行时 / 核心 / UI / 主程序）
├── assets/               # 图片、Logo、第三方库（three.js 等）
├── ReadingPractice/
│   └── PDF/              # 雅思阅读真题 PDF（P1/P2/P3 共 260+ 篇）
└── spec/                 # 功能规格说明（单词系统等）
```

## 🛠 技术栈

- **前端**：原生 HTML / CSS / JavaScript（无框架、无构建步骤）
- **可视化**：Canvas 手绘图表（趋势图、热力图、雷达图、指针时钟）
- **3D 背景**：three.js（动态主题）
- **记忆算法**：SM-2（SuperMemo 2）间隔重复
- **本地服务**：Node.js 原生 `http` 模块，零第三方依赖

## 🔒 隐私说明

所有练习记录、错题、单词进度、备份数据均保存在**你自己的浏览器本地**，不会上传到任何服务器。清除浏览器数据前请先使用「导出数据」功能备份。
